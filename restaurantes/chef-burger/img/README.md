# Fotografias do Chef Burger

Estas imagens são referências de alta resolução, licença [Unsplash](https://unsplash.com/license), para a proposta de site.
Não são fotografias do restaurante e não vêm do site da Webomarketing.

Para usar as fotos do Instagram, grave um ficheiro **com o mesmo nome** por cima do que está aqui (WebP, de preferência).
Não é preciso mudar o HTML. O logótipo é `logo.svg`: pode ser SVG ou, se for outra extensão, atualize o `src` no cabeçalho.

Largura útil: hero cerca de 1400 px; categorias cerca de 1200 px. Proporção livre: o site corta com `object-fit: cover`.
